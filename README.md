# **TANSYITUL FINANCIAL MANAGEMENT APP**
### **Role:** Programmer
***

## 💬 About App
Tansyitul Financial Management is a financial management application specifically designed to simplify the work of the treasurer of Madrasah Ibtidaiyah (MI) Tansyitul Muta'allimin in compiling school financial reports. This application has several key features that make the treasurer's work easier and more efficient, such as menus for compiling income and expenditure reports, and a menu for printing summary information from the data that has been entered.
***

## 🛠 Tools
| Tools | Functional |
| ----- | ---------- |
| Dart | **Programming language** integrated with the Flutter framework |
| Flutter | **Framework** for developing applications |
| Visual Studio Code | **Code editor** for developing applications |
| GitHub | Code version control |
| Postman | Perform API testing |
| Vysor | Mobile phone screen mirror |
***

## 🚀 Applications Features
- General School Information
- Information About the Number of Students Enrolled in the School
- Information About School Cash Income Based on a Specific Period
- Information About School Cash Expenditures Based on a Specific Period
- School Cash Income Management
- School Cash Expenditure Management
- Print School Cash Income and Expenditure Data
